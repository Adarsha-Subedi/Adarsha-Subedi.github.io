# Adarsha-Subedi.github.io

Personal academic website for Adarsha Subedi, hosted with GitHub Pages.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait a few minutes, then visit https://adarsha-subedi.github.io.

## Customize

- `index.html`: all page text and sections.
- `style.css`: colors, layout, typography, and responsive styling.
- `script.js`: mobile navigation, theme toggle, and footer year.
- `favicon.svg`: browser tab icon.

## Before sharing

Add verified details only: university/department, academic email, CV PDF, publications, working-paper links, and professional profiles. Update the research and teaching descriptions to match your current work. The current page intentionally avoids claiming an affiliation, publication, or teaching appointment that has not been confirmed.

The site uses Google Fonts for Source Serif 4 and DM Sans, with Georgia/Arial fallbacks.
