# Adarsha Subedi — Academic website

This site uses the **AcademicPages** Jekyll theme (based on Minimal Mistakes), matching the structure and layout style of https://cannoncloud.github.io/.

## Publishing

In GitHub, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/(root)`. If Pages is already enabled, new commits will trigger a rebuild automatically. Check the **Actions** tab if a deployment does not complete.

## Edit your details

- `_config.yml`: name, sidebar bio, location, employer, email, profile photo, and academic/social profile links.
- `_data/navigation.yml`: top navigation.
- `_pages/about.md`: homepage biography.
- `_pages/research.md`: research interests and papers.
- `_pages/teaching.md`: teaching experience.
- `_pages/cv.md`: CV page.
- `images/profile.svg`: temporary profile-photo placeholder; replace it with a portrait and update `author.avatar` in `_config.yml`.
- `files/`: upload your CV PDF and other downloadable documents here.

## Placeholders to complete

Add only verified details: current degree/position, university/department, academic email, office/location, profile photo, CV PDF, publication records, teaching experience, and Scholar/ORCID/LinkedIn links. The site intentionally does not invent any of these.

The AcademicPages theme is loaded from `academicpages/academicpages.github.io` using Jekyll's remote-theme support. The theme's source and documentation are at https://github.com/academicpages/academicpages.github.io.
